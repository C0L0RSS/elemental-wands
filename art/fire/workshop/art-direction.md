## Preview treatment

The returned image has real transparency, with some very faint edge alpha. The
browser's cutout shader discards alpha below 0.5 for these six custom families;
the image file itself is preserved. Atlas cells are selected directly by UV.
The low-wisp row uses a vertical UV crop to use its narrow horizontal silhouette
efficiently. No vanilla artwork is inserted into the custom atlas.
