## Using this vault

- Start here instead of the graph. Click a note above to open it.
- Edit a note to write ideas or decisions. Changes save automatically.
- Use the magnifying glass to search, or the quick switcher to find a note by name.
- The graph shows links between notes; it is optional, not a task-status board.
- Put an uncommitted thought in Ideas. Once agreed, put the decision in Vision
  and create or update its work item in Progress.
- Add a short dated entry to Updates after a session. Keep detailed code/test
  reports in the repository and link them from here.
